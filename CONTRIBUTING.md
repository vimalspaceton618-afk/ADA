# Contributing

Thanks for your interest in ADA.

## Current stage

The repository is an architecture scaffold. Before adding implementation, document the subsystem's purpose, interfaces, dependencies, failure modes, data handling, and evaluation plan.

## Guidelines

- Keep changes focused and explain the architectural reason.
- Add tests for executable behavior.
- Record research claims with primary sources and reproducible evidence.
- Preserve provenance, licensing, privacy, and security requirements for data.
- Make autonomous or self-modifying behavior sandboxed, reviewable, and reversible.
- Never commit secrets, credentials, private datasets, or generated model weights.

## Pull requests

Describe the change, relevant subsystem, tests run, risks, and migration implications.
