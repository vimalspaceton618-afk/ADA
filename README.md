# ADA

ADA is an experimental research project exploring adaptive, continuously learning intelligent systems.

## Repository status

This repository establishes the initial architecture-oriented directory scaffold. The directories are organizational boundaries, not claims that capabilities are already implemented.

## Architecture map

The numbered directories define proposed system domains, from foundations and initialization through cognition, learning, evaluation, safety, deployment, research, and operations.

## Research discipline

- Treat architectural capabilities as hypotheses until implemented and evaluated.
- Keep learning and structural changes versioned, measurable, reversible, and permission-controlled.
- Record data provenance, licensing, privacy constraints, and evaluation results.
- Do not describe ADA as human-level or superintelligent without reproducible evidence.

See CONTRIBUTING.md for initial contribution guidelines.
